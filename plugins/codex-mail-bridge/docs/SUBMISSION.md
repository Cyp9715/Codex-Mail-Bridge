## Remaining preparation

1. Confirm the submitting organization is approved for local MCP submissions
   with the OpenAI representative. Official [desktop-only instructions](https://developers.openai.com/plugins/deploy/desktop-only)
   require organization allowlisting; no approval is assumed.
2. Complete developer/business verification for the intended Cyp Soft identity.
3. Record real host interactions with isolated synthetic Thunderbird mail and a
   dedicated classic Outlook test profile. Do not show production mail or inject
   mock tool results into a purported live Outlook recording. Play back the actual
   recording, inspect privacy/readability, and host it at a reviewer-accessible URL.
   Only after verification add review.demo_recording_url and rebuild the ZIP.
4. Confirm reviewer access to a supported Windows/classic Outlook test setup.
   No production credentials belong in a ZIP or public issue. Record secure
   access details in the portal only where required.
5. Upload a draft, verify imported values, run portal/host checks, and have the
   authorized developer complete attestations before a separately authorized review submission.

The package is a development/submission-preparation bundle, not a completed
public submission. ZIP validation, private installation, review submission,
approval, and publication are separate states. Demo recording and verification
are not claimed complete. See the packaged REVIEW walkthrough.
